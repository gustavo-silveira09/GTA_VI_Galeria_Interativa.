# galeria_interativa

# GTA VI — Vice City Experience

Galeria interativa inspirada no universo de GTA VI.

## Descrição

Projeto desenvolvido com HTML, CSS e JavaScript,
apresentando imagens, legendas e navegação interativa.

## Tecnologias

- HTML
- CSS
- JavaScript
- Git e GitHub

## Funcionalidades

- Navegação entre imagens.
- Botões anterior e próxima.
- Legendas dinâmicas.
- Contador de fotos.
- Apresentação automática.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta no VS Code.
3. Abra o arquivo index.html no navegador.
